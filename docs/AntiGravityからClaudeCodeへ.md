# AntiGravity から Claude Code への切り替え手順

AntiGravity でこの動画ツールを使っていた方向けの手順です。上から順に進めれば切り替えが終わります（約1時間。Claude Code が入っていれば10分）。

## 何が変わるの？

| | これまで（AntiGravity） | これから（Claude Code） |
|---|---|---|
| 頼み方 | 決まった文をコピーして貼る | 「動画作って」と送るだけ |
| 仕上がりの確認 | 自分で動画を見て探す | **Claude が書き出したコマを見て、テロップの重なりなどを直してから** 報告してくれる |
| BGM | 3曲から番号で選ぶ | 日本の定番フリー素材（BGMer）から最大8曲。おすすめ3曲に理由つき。番号で選ぶ |
| 入れるもの | スライド（PDF）と台本 | 同じ |

## 0. 用意するもの

- **Claude の有料プラン（Pro 以上）**。Claude Code は無料プランでは使えません
- これまで使っていた動画ツールのフォルダ（そのまま使います。`inbox` の素材・`.env`・BGM の曲は消えません）

## 1. Claude Code を入れる（初めての方だけ）

次のページの手順どおりに進めてください。コピーして貼るだけで終わります。

https://claude-code-setup.pages.dev/

「5. VS Code を入れて、道具を使い分ける」の最後の確認まで終われば準備完了です。

## 2. 動画ツールのフォルダを Claude Code で開く

1. VS Code を開く
2. メニューの「ファイル」→「フォルダーを開く」で、**これまで AntiGravity で開いていた動画ツールのフォルダ** を選ぶ
3. メニューの「ターミナル」→「新しいターミナル」を開く
4. 下の1行をコピーして貼り、Enter

```
claude
```

## 3. 最初に1回だけ送る

Claude Code が起動したら、下の文をそのままコピーして送ってください。

```
このフォルダの動画ツールを最新にして（git pull origin main）、環境チェックをして。
足りないものがあれば、入れ方を1つずつ教えて。
```

「〇〇を実行してよいですか？」と聞かれたら、内容を読んで「Yes」を選んでください。

## 4. 動画を作る（毎回）

1. `inbox` フォルダの中に動画名のフォルダを作り、スライドの PDF と台本（`.md`）を入れる
2. Claude Code に送る

```
inbox の素材で動画作って
```

3. BGM の候補が出たら（おすすめ3曲＋ほか最大5曲）、プレビューを聴いて「2番で」のように番号を返す
4. 数分待つと、Claude が仕上がりを確認・手直ししてから「完成しました」と報告します

完成した動画は `output/<動画名>/final.mp4` にあります。
BGM に「CC BY」と書かれた曲を選んだときだけ、`output/<動画名>/credits.txt` の1行を動画の概要欄に貼ってください（BGMer の曲は表記不要）。

スライドを作るときは、**大事な文字や図を画面の上80%に置いてください**。下20%には動画のテロップが重なります。

## うまくいかないとき

| 困ったこと | どうする |
|---|---|
| `claude` と打っても動かない | 1. のページの「エラー逆引き」を見る |
| 「環境が足りない」と言われた | Claude が出した入れ方を上から順に実行する（分からなければ「もっと簡単に説明して」と送る） |
| 声が機械っぽい | 高品質な声（Fish Audio）の API キーが入っていません。fish.audio でアカウントを作り、Claude に「Fish Audio の API キーを設定したい」と送ると入れ方を案内してくれます。キーが無くても動画は作れます（標準の声になります） |
| Windows で動かない | Windows ではまだ動作確認をしていません。表示されたエラーをそのまま Claude に送って相談してください |
