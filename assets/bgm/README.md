# BGM ライブラリの使い方

ここに置いた音楽ファイルが、動画の雰囲気に合わせて自動で選曲されます。
**合成音・効果音ではなく「音楽」を置いてください**（過去に ffmpeg で合成した持続音を置いてしまい、動画全体が「ブーン」という音になった事故があります。品質ゲートが LRA<1.2 LU の持続音を検知して警告します）。

## フォルダ構成

```
assets/bgm/
├── relaxing/   落ち着いた・穏やかな曲（会社紹介・解説・医療・教育）
├── upbeat/     明るい・テンポの良い曲（商品PR・キャンペーン）
└── serious/    真面目・静かな曲（報告・データ解説）
```

各フォルダに **2〜3曲ずつ** 入れておくと、動画ごとにタイトルのハッシュで決定的に1曲が選ばれます（同じ動画名なら毎回同じ曲）。

## 音楽ファイルは git にコミットしない（重要）

この GitHub リポジトリは**公開**です。フリー素材の多くは「作品への組み込みは可・ファイルそのものの再配布は不可」なので、音楽ファイルは `.gitignore` で除外してあります（`assets/bgm/*/*`）。
**動画を作る PC ごとに、このフォルダへ音楽ファイルを置いてください。** 何を置いたかは `LICENSES.md` に記録し、そちらはコミットして構いません。

## ファイルの条件

| 項目 | 条件 |
|------|------|
| 形式 | mp3 / wav / m4a / aac / flac / ogg |
| 長さ | **15秒以上**（それ未満は自動で除外）。動画より短い曲は自動でクロスフェード連結してループします |
| 内容 | ボーカルなし推奨（ナレーションと被るため） |
| ライセンス | 商用利用可・クレジット表記の要否を確認し、`LICENSES.md` に必ず記録 |

## 入手先の例（無料・商用可のもの）

- DOVA-SYNDROME（https://dova-s.jp/）— 商用利用可・多くはクレジット不要（曲ごとの利用規約を確認）
- 甘茶の音楽工房（https://amachamusic.chagasi.com/）— 商用利用可・クレジット不要
- YouTube オーディオ ライブラリ — YouTube 上での利用が主。他媒体は各曲の帰属表示条件を確認

## 自動で候補を探す（Openverse）

`./run.sh --bgm-candidates --project <動画名>` で、Openverse（Creative Commons 素材の横断検索・無料）から **CC BY / CC0 の楽曲だけ**を探し、3候補のプレビューを作ります。選んだ曲（`--bgm-choose N`）はこのフォルダに保存され、隣に `<ファイル名>.json`（出典・ライセンス・クレジット文）が置かれます。この JSON があると本番生成時に `output/<動画名>/credits.txt` が自動で作られます。

- CC BY の曲 → 動画の概要欄に `credits.txt` の1行を貼る（必須）
- CC0 の曲 → クレジット不要
- 手持ちで追加した曲は JSON が無いので、`LICENSES.md` に自分で条件を書く

## 台本から曲を指定する

`script.md` の先頭に1行書くと、自動判定より優先されます。

```markdown
# BGM: upbeat            ← フォルダ（ムード）を指定
# BGM: morning_walk.mp3  ← ファイル名を直接指定（全フォルダから検索）
# BGM: none              ← BGM なし
```
