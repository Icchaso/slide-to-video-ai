# make-video — スライド＋台本 → 仕上がった動画

このツールの仕事は **「持ち込まれたスライドと台本を、見る人にとって一番分かりやすい動画にする」** こと。
台本とスライドは作らない・書き換えない（別スキルの担当）。足りなければ依頼して止まる。

エンジンは `./run.sh`（`src/main.py`）。Claude は **判断する役** で、判断はファイルに書いてエンジンに渡す。
同じファイルなら毎回同じ動画になる（決定性）。

## 完了の条件（全部そろって初めて報告する）

1. `output/<動画名>/final.mp4` があり、終了コードが `0`
2. `build_summary.json` の `status` が PASS か WARN（WARN は全部に理由を付けて報告）
3. **下書きの自己レビューで指摘ゼロ**、または残した指摘に理由がある（最大2周まで直す）
4. BGM は人間が番号で選んだ曲（勝手に決めない）

## 手順

### ① 素材の確認
- `inbox/<動画名>/` に PDF 1つ・台本 `.md` 1つがあるか
- 無い／台本に `# Slide N` が無い → **作らずに** 人間に置いてもらうよう伝えて止まる
- `./run.sh --check` → 終了コード `2` なら表示された導入コマンドを案内して止まる（`brew` を自分で実行してよいか確認する）
- PDF の各ページ画像を見て、台本の `# Slide N` と中身が合っているかを確認（ずれていたら人間に確認）

### ② BGM（台本に `# BGM:` が無いとき）
1. `./run.sh --bgm-candidates --project <動画名>`（数十秒〜数分。Openverse が遅い）
2. 候補表（曲名／作者／ライセンス／長さ）とプレビュー `output/<動画名>/bgm_candidates/*.mp3` のパスを見せ、**番号を選んでもらう**
3. 「N番で」→ `./run.sh --bgm-choose N --project <動画名>`
4. 気に入らなければ `--bgm-query "<英語1語>"` で出し直す

### ②' 声（読み方辞書と読み上げチェック）
1. 台本を読み、**声が読み間違えやすい語** を先回りして `inbox/<動画名>/reading.json` に書く（音声に渡す文字だけが変わり、テロップは台本のまま）
   - 対象: 数字＋助数詞（`1本`→`いっぽん`）、英字略語（`SaaS`→`サース`）、固有名詞・人名・地名、読みが割れる漢字（`行った` `人気` `大分` `生物` `最中` `今日`）
   ```json
   { "SaaS": "サース", "1本": "いっぽん", "大分県": "おおいたけん" }
   ```
   - 長い表記から順に置き換わる。台本にある字面をそのまま書く
2. `./run.sh --voice-check --project <動画名>` → `work/<動画名>/voice_check.md`
   - 文ごとに音声を文字起こしし、台本と **ひらがなの読み** で照合する（同音異字の書き起こし違いは一致扱い）
   - ⚠️ は「一致率 0.9 未満」または「2文字以上のずれ」。**文字起こし側の誤り（「台本」→「大本」、助詞の脱落）も混ざる**ので、ずれの箇所を見て「声が本当に違う読みをした」ものだけ辞書に足して再実行（最大2周）
   - 漢字の読み違いは、文字起こしが文脈で正しい漢字に直してしまい検出できないことがある。1. の先回りを省略しない
3. 間（ま）を変えたい場面は storyboard.json の `gap`（文と文の間の秒数。0〜2、既定 0.18）で指定する
4. ログに `Fish Audio に失敗し N文が edge-tts の声` と出たら、キー失効（401）か残高不足（402）。人間に `.env` の更新を依頼する

### ③ 絵コンテ（storyboard.json）を書く
PDF の各ページ画像（`work/<動画名>/slides/slide_NNN.png`。無ければ ④ の下書きで作られる）を **全部見て**、場面ごとの指定を `inbox/<動画名>/storyboard.json` に書く。台本とスライドは書き換えない。

```json
{
  "version": 1,
  "default": { "subtitle": "band" },
  "slides": {
    "1": { "subtitle": "off", "note": "表紙はタイトルを読み上げるだけなのでテロップ不要" }
  }
}
```

| subtitle | 使いどころ |
|---|---|
| `band`（既定） | スライドは画面いっぱい。テロップは下 20% の中に重ねる。**スライドの中身は上 80% に置く約束**（いっちゃん指定の標準 2026-09-17） |
| `bottom` | 下端から 58px の位置に重ねる（従来の位置） |
| `top` | 上端から 58px の位置に重ねる。スライドの中身が下 20% にはみ出しているときの逃げ道 |
| `off` | テロップを出さない場面（スライドの文字をそのまま読み上げる表紙など） |

- 場面ごとに `"gap": 0.4` のように文と文の間（秒）も指定できる（強調したい数字の前後など）
- スライドの中身が下 20% にはみ出していてテロップと重なる場面は、`top` に逃がすか、スライドを作る側（別スキル）に直してもらうよう報告する
- 判断の理由を `note` に1行書く（次に直す人が分かるように）
- 誤ったキーや値はエンジンがエラーで止める。メッセージどおりに直す

### ④ 下書き → 自己レビュー（省略禁止・最大2周）
1. `./run.sh --draft --project <動画名>`（全尺は書き出さない。数十秒で終わる）
   → `work/<動画名>/review/` に **テロップ1枚ごとの表示中央のコマ** と一覧 `frames.md` ができる
2. `video-reviewer` エージェントを起動し、次を渡す（画像は本体で開かない。文脈が膨らむため）:
   - コマのフォルダ `work/<動画名>/review/` と一覧 `frames.md`
   - 台本 `inbox/<動画名>/script.md`、`inbox/<動画名>/storyboard.json`
   - 「チェック表の全項目を確認し、テロップ位置の直し方（top / band / bottom）をスライド単位で返して」
3. 指摘を storyboard.json に反映して 1 に戻る。**2周しても残る指摘**、または直す手段が無い指摘は、直さずに理由をつけて報告に残す

### ⑤ 本番の書き出し
- `./run.sh --project <動画名>` を **run_in_background** で実行し、完了通知を待つ（途中で止めない。ログは `work/<動画名>/run.log`）
- `build_summary.json` の `checks[]` で PASS 以外を全部読む。FAIL は下の対処表で直してやり直す
- `output/<動画名>/contact_sheet.jpg` で、下書きで直した場面が本番でも直っているかを確認する

### ⑥ 報告（短く）
- status／尺／LUFS／BGM の曲名／TTS エンジン
- WARN・FAIL と、自己レビューで直したこと・残った指摘（理由つき）
- 動画のパス
- BGM が CC BY なら「`output/<動画名>/credits.txt` の1行を概要欄に貼る」

## WARN / FAIL の対処表

| 表示 | 意味 | 対処 |
|---|---|---|
| `BGM: BGM なし` (WARN) | 曲が割り当てられていない | ② をやる。曲なし納品も可 |
| `--bgm-candidates` が終了コード 3 | 候補ゼロ／Openverse 不通 | `--bgm-query` を変える。数分待つ。`assets/bgm/<mood>/` の手持ちから選ぶ |
| `BGM: … 持続音の可能性` (WARN) | 音楽でない合成音 | 曲を差し替える。**合成音を BGM にしない** |
| `TTS: … edge-tts にフォールバック` (WARN) | Fish Audio が失敗（401 キー失効／402 残高） | `.env` の `FISH_AUDIO_API_KEY` 更新を人間に依頼。edge-tts のまま納品してよいか確認 |
| `TTS: … 無音で代替` (FAIL) | ネット不通 | 接続を直して再実行 |
| `台本: スライド N は台本がない…` (WARN) | 台本が無いスライドは動画に入らない | 意図どおりか人間に確認 |
| `ラウドネス` / `トゥルーピーク` | 音量が基準外 | 再実行。続けば `run.log` の測定値を添えて報告 |
| `尺` (FAIL) | レンダ結果の長さ違い | `run.log` のレンダ部分を読んで再実行 |
| `テロップ: 0枚` (FAIL) | テロップが出ない | 台本の本文が空でないか確認 |
| `lint: エラー N件` | コンポジション不整合 | `cd hyperframes-app && npm run check` で詳細 → `src/template.html` / `src/main.py` の生成部を直す |
| `reading.json の誤り` / `JSON として読めません` | 辞書の書式違い | `{"表記": "読み"}` の形に直す |
| `storyboard.json の誤り: …` / `JSON として読めません` | 絵コンテの書式違い | 表示された項目を直す（使えるキーは ③ の表） |
| 終了コード `1` | 例外 | `work/<動画名>/run.log` の `[ERROR]` と traceback を読んで自分で直す |

## やってはいけないこと
- 台本の文言・スライドを書き換える（読み方は reading.json、演出は storyboard.json で指定する）
- BGM を人間に選ばせずに決める
- 品質ゲート FAIL・自己レビュー未実施のまま「完成」と報告する
- `hyperframes-app/index.html` を手で編集する（毎回上書きされる）
- Openverse 以外の素材サイトからスクリプトで自動取得する
